# DesktopSalesApp
Java Swing Sales Application
This is a desktop sales application developed using Java and the Swing GUI framework.I developed this project to reinforce my basic Java concepts, database operations and GUI development skills.

🚀 Features
🧾 Customer management (Add, Update, Delete)
📦 Product management (Add, Update, Delete)
🔐 User authentication (Register & Login)
🛒 Shopping cart functionality
🔍 Filtering products and customers
🗃️ Persistent data storage using MySQL
🎨 User-friendly interface built with Swing

🛠️ Technologies Used
Java 
Swing (Graphical User Interface)
JDBC (Java Database Connectivity)
MySQL (for database management)

🎯 Purpose
This project was developed for educational purposes to improve skills in:
Core Java 
GUI design using Swing
Database operations (CRUD)
Structuring and organizing a complete Java application
